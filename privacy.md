# COMPR Privacy Policy

Last updated: August 9, 2026

COMPR is a browser extension that helps users save and compare clothing products from different online stores.

## Information COMPR processes

COMPR processes product information from the webpage that the user is viewing. This may include:

- Product name
- Price
- Brand
- Product image
- Color
- Material
- Size
- Product category
- Store name
- Product URL

This information is used only to provide COMPR's product-saving and comparison functionality.

## Local storage

Products that a user chooses to save are stored locally using browser extension storage so that they remain available for comparison.

COMPR does not require users to create an account.

## Personal information

COMPR does not intentionally collect personal information such as names, email addresses, passwords, payment information, health information, or precise location information.

## Data sharing

COMPR does not sell user data.

COMPR does not transfer user data to third parties for advertising, creditworthiness, lending, or purposes unrelated to COMPR's product comparison functionality.

## Remote code

COMPR does not use remotely hosted executable code. The JavaScript required for the extension is included within the extension package.

## Changes to this privacy policy

This privacy policy may be updated when COMPR's functionality changes. The latest version will be published on this page.

## Contact

For questions about this privacy policy or COMPR, please use the support contact information provided on the COMPR Microsoft Edge Add-ons listing.
