# COMPR marketing capture guide

Use only the production candidate build with test/Sandbox accounts. Revalidate every retailer price immediately before capture. Never show email addresses, tokens, extension IDs, Stripe IDs, browser history, bookmarks or developer consoles.

## Capture sizes

- Chrome Web Store: 1280×800 (at least two clean screenshots).
- Promotional tile: 440×280.
- Marquee: 1400×560.
- Website desktop: 1440×900.
- Website mobile: 390×844.
- Short video: 1080×1920, cursor initially outside the primary card.

## Required states

1. Product detected: complete name, model/identifier, colour and current price.
2. Find This Cheaper loading: no personal data or debug details.
3. Better price found: current price, best trusted offer and **Potential saving**.
4. Multiple matches: Exact/Strong first, Likely labelled, Possible collapsed.
5. Save & Compare: two genuine test products with clean images.
6. Free account: remaining searches visible.
7. Founding upgrade: real configured prices, no fake countdown or remaining-member claim.
8. Pro and Ultimate: separate Sandbox accounts with genuine server entitlements.
