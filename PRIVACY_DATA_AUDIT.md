# COMPR v0.3 privacy and data audit

Audit date: 2 September 2026
Scope: `V.0.3-prototype/`, the production output rules in `tools/build-production-extension.ps1`, `find-cheaper-backend/`, and `website-live/`.

This is a factual engineering audit, not legal advice. Archive folders (`compr/`, `V.0.2.3/`, `github-upload/`, `backups/`) and media tooling are not shipped in the v0.3 production extension.

## Storage and tracking not found

- No analytics SDK, advertising pixel, crash-reporting SDK, affiliate rewriting or behavioural advertising code was found.
- No WebSocket use was found.
- No extension cookies, `chrome.storage.sync`, IndexedDB or extension `localStorage` use was found.
- The public website uses `localStorage` only for language and a temporary Founding-interest plan/source value.
- No full browsing-history API access or background collection across tabs was found.
- No payment-card number is received or stored by COMPR; future card entry would be hosted by Stripe.

## Permissions and exposed resources

| Item | Needed now | Reason / action |
|---|---:|---|
| `storage` | Yes | Saved products, preferences, cached rates and authentication session use `chrome.storage.local`. |
| `activeTab` | Yes | Grants temporary access to the tab on which the user invokes COMPR. No permanent all-sites permission is requested. |
| `scripting` | Yes | Detector files are injected only into the active tab when the popup is opened. |
| COMPR backend host | Yes | Authenticated account and price-check requests. Production build requires HTTPS. |
| Supabase host | Yes | OTP login, session refresh/logout and authentication. Production build requires HTTPS. |
| ECB host | Yes | Public exchange-rate XML used by the existing currency conversion feature. The build script previously dropped this required host and now retains it. |
| `externally_connectable` | No | The website never calls the extension through external messaging. It was removed. |
| Web-accessible scripts | No | Only `auth-receiver.html` needs to be navigable from the callback page. Its dependent scripts run inside the extension and were removed from the exposed-resource list. |

## Open facts requiring manual confirmation

1. The legal/operator name and postal/country details to publish are not present in the repository; only the support email is known.
2. Render's actual log-retention period and plan settings are not encoded in the repository.
3. Supabase, Brevo, Brave, GitHub Pages and ECB provider-side retention must be checked against the active accounts/current provider terms.
4. Migration `011_data_retention_and_account_deletion.sql` must be applied before the cleanup RPC and cascading account deletion work in production.
5. The server defaults are 30 days for search records, 90 days after period end for usage periods, 1 day after expiry for checkout reservations, and 24 hours for cache. Production environment values must be checked against these documented values.
6. Stripe code exists but the submitted beta is configured not to start payment. Accounts unexpectedly linked to a Stripe subscription are deliberately blocked from self-service deletion until a safe cancellation/legal-retention process exists.
